# 🌐 My Progressive Web App (PWA)

This is a Progressive Web App (PWA) built with the minimum necessary [3 main files: HTML/CSS/JS, manifest, service worker] and hosted on **GitHub Pages**. 
It supports offline usage, installability, and a responsive mobile-first experience (still a work in progress).
The app features a minimalist design.
The app intends to help newcomers to the German language learn vocabulary.

# How does it work ?
Open the app; the app welcomes you.
Hit the start button, and  it will show a screen with word information.

```
+-------------------------------------------+
|                                           |
|                word. index                |
|               (article) Word              |
| (article pl.) Plural word (if applicable) |
|            Example with the word          |
|                                           |
|                                           |
|            Spanish translation            |
| Lection #: Title of the lection - level   |
|                                           |
|                                           |
|        previous    random    next         |
|                                           |
+-------------------------------------------+
```

Here is where all the magic happens.
Learn words by reviewing them, going forward and backward, 
Or pick a random word. Learn and enjoy!

## 📦 Features

- ✅ Offline support via Service Worker
- ✅ Installable on mobile and desktop
- ✅ Mobile-first responsive design
- ✅ Works without a backend
- ✅ Hosted for free on GitHub Pages

## 🧰 Tech Stack

- [No Framework]
- HTML5, CSS, JavaScript.
- [Service Worker]
- GitHub Pages [Free-Host]

## 🛠️ Installation

To run the app locally:

```bash
# Clone the repository
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```
